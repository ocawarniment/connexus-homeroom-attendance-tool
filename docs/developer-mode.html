Admin guide

Developer Mode

A few extra tools for safely checking CHAT’s attendance guidance. Tread lightly: these controls are intended for administrators and testers.

Getting started

Turn on Developer Mode

  1. Open the CHAT side panel and select Settings.
  2. Click the small Info icon beside About ten times.
  3. A Developer Settings card will appear.
Use a test section when possible: Developer Mode is for validating behavior, not for regular attendance work.

Ledger testing

Test attendance guidance

Select the school you want to review, then turn on Load CHAT Ledger Test Students in Developer Settings.

  • CHAT creates one clearly labeled test student for every attendance scenario configured for that school.
  • The test-student name describes the rule being checked, while the action button shows the expected guidance.
  • Switch schools while the setting is on to generate that school’s set of scenarios.
  • Turn the setting off to restore the roster that was visible before testing.
Important: Test students are not real Connexus students. Do not select their attendance action buttons or use them to create logs or messages.

Other tools

Additional developer settings

Download all students
Includes students regardless of their current Connexus stage, so you can inspect how CHAT handles a fuller roster.
Redact student names
Replaces displayed names with a generic label when sharing screenshots or demonstrating CHAT.
Randomize overdue counts
Varies overdue-lesson values to help review table display and attendance guidance.

When you are done

Return to regular use

Turn off Load CHAT Ledger Test Students first, then close Settings. Developer Mode remains available on that browser profile, but its test controls do nothing unless you turn them on again.
