Extension releases and CHAT Ledger updates for the current school year.

Recent changes

The plum icon identifies CHAT extension releases. The blue icon identifies CHAT Ledger updates, which can be retrieved from Settings without reinstalling CHAT.

⌘

Extension

CHAT 4.0.2

  1. September 2026Create Log fixes. The log workflow now checks that the required attendance details are present and uses the current Connexus form controls instead of fixed positions, making it more dependable when the form changes.
  2. September 2026Safer developer testing. Developer Mode can open a clearly marked draft log when there are no adjustments; CHAT never submits that draft automatically.
  3. September 2026Overdue-lesson downloads restored. Homeroom teachers can again retrieve overdue-lesson data for the selected completion measure.
▤

CHAT Ledger

Ledger 2.0.17

  1. September 2026Time-deficit guidance is blue. When a student is keeping up with lessons but has fewer logged hours than required, the guidance now uses an informational blue cue rather than an error color.
  2. August 2026Attendance guidance refined. Ledger 2.0.14 added OHBCA configuration and clarified guidance for engagement, review, and adjustment scenarios.
  3. August 2026Unused escalation-status field removed. Ledger 2.0.15 removes that measure from the configured school data views.
